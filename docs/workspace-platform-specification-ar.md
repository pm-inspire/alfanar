## 1. نظرة عامة على النظام

### 1.1 وصف المنصة

منصة سحابية متكاملة تتيح لأصحاب المكاتب ومزودي مساحات العمل عرض وإدارة قاعات الاجتماعات ومساحات العمل المشتركة. تمكّن المنصة المستخدمين النهائيين من استعراض المساحات المتاحة، والاطلاع على الأوقات الشاغرة، وإجراء الحجوزات بشكل مباشر.

### 1.2 المشكلة التي يحلها النظام

- صعوبة إيجاد مساحات عمل مناسبة للاجتماعات والعمل المؤقت
- عدم وجود منصة موحدة لعرض المساحات المتاحة في المنطقة
- تعقيد عملية الحجز التقليدية (اتصالات هاتفية، رسائل بريدية)
- صعوبة إدارة الجداول والحجوزات لدى مزودي الخدمة
- غياب الشفافية في الأسعار والتوافر

### 1.3 القيمة المضافة

| للمستخدمين النهائيين | لمزودي المساحات |
|---------------------|-----------------|
| البحث السريع عن المساحات | إدارة مركزية للحجوزات |
| الحجز الفوري عبر الجوال | تقليل الأعباء الإدارية |
| مقارنة الأسعار والخدمات | زيادة معدل الإشغال |
| تقييمات ومراجعات موثوقة | تحليلات وتقارير تفصيلية |
| إدارة الحجوزات بسهولة | تحصيل الدفعات آليًا |

## 2. أهداف المنصة

### 2.1 الأهداف الرئيسية

1. **تسهيل الوصول**: توفير منصة موحدة للبحث والحجز
2. **تحسين الكفاءة**: أتمتة عمليات الحجز والإدارة
3. **زيادة الإيرادات**: رفع معدل إشغال المساحات لدى المزودين
4. **تعزيز الثقة**: توفير نظام تقييمات ومراجعات شفاف

### 2.2 الأهداف القابلة للقياس

- تقليل وقت عملية الحجز بنسبة 80%
- رفع معدل إشغال المساحات بنسبة 30%
- تحقيق معدل رضا عملاء لا يقل عن 4.5/5
- تقليل معدل الإلغاءات إلى أقل من 5%

### 3.2 تطبيق الجوال (Android و iOS)

**الوصف**: تطبيق للمستخدمين النهائيين يتيح تصفح المساحات والحجز المباشر

**المنصات المدعومة**:
- نظام Android (الإصدار 8.0 فأعلى)
- نظام iOS (الإصدار 13.0 فأعلى)

**تقنية التطوير**: 
- تطوير أصلي (Native) أو عبر إطار عمل متعدد المنصات (Flutter/React Native)

### 3.3 لوحة التحكم الإدارية (Web Panel)

**الوصف**: واجهة ويب شاملة لإدارة المساحات والحجوزات

**المتصفحات المدعومة**:
- Google Chrome (أحدث إصدارين)
- Mozilla Firefox (أحدث إصدارين)
- Safari (أحدث إصدارين)
- Microsoft Edge (أحدث إصدارين)

**التصميم**: متجاوب (Responsive) يدعم الشاشات المختلفة

### 3.4 واجهة برمجة التطبيقات (API)

**النوع**: RESTful API

**المعايير**:
- استخدام بروتوكول HTTPS حصريًا
- توثيق شامل بمعيار OpenAPI 3.0
- دعم معدل طلبات محدود (Rate Limiting)
- إصدارات متعددة للتوافق (API Versioning)

## 4. أدوار المستخدمين والصلاحيات

### 4.1 المستخدم النهائي (End User)

**الوصف**: الشخص الذي يبحث عن مساحات عمل ويقوم بالحجز

| الصلاحية | الوصف |
|----------|-------|
| تصفح المساحات | عرض جميع المساحات المتاحة مع التفاصيل |
| البحث والتصفية | البحث حسب الموقع، السعر، الخدمات، التقييم |
| عرض التوافر | الاطلاع على الأوقات المتاحة للحجز |
| إنشاء حجز | حجز مساحة لفترة زمنية محددة |
| إدارة الحجوزات | عرض، تعديل، إلغاء الحجوزات الخاصة |
| الدفع الإلكتروني | إتمام عمليات الدفع عبر التطبيق |
| التقييم والمراجعة | إضافة تقييمات ومراجعات بعد الاستخدام |
| إدارة الملف الشخصي | تحديث البيانات الشخصية وإعدادات الحساب |
| استلام الإشعارات | تلقي إشعارات الحجز والعروض |

### 4.2 مزود المساحة (Workspace Provider)

**الوصف**: مالك أو مدير مساحات العمل وقاعات الاجتماعات

| الصلاحية | الوصف |
|----------|-------|
| إدارة المساحات | إضافة، تعديل، حذف المساحات |
| إدارة الصور والوسائط | رفع وتنظيم صور ومقاطع فيديو المساحات |
| تحديد الأسعار | وضع أسعار الساعة/اليوم مع العروض الخاصة |
| إدارة الجداول | تحديد أوقات العمل والتوافر |
| معالجة الحجوزات | قبول، رفض، تعديل طلبات الحجز |
| عرض التقارير | الاطلاع على تقارير الإيرادات والإشغال |
| إدارة الموظفين | إضافة مستخدمين فرعيين بصلاحيات محددة |
| التواصل مع العملاء | الرد على استفسارات ومراجعات العملاء |
| إدارة الإعدادات | تخصيص سياسات الإلغاء والدفع |

### 4.3 مدير النظام (System Admin)

**الوصف**: مسؤول عن إدارة المنصة بالكامل

| الصلاحية | الوصف |
|----------|-------|
| إدارة المزودين | الموافقة على مزودي الخدمة الجدد وإدارة حساباتهم |
| إدارة المستخدمين | إدارة جميع حسابات المستخدمين |
| إدارة المحتوى | التحكم في المحتوى المعروض على المنصة |
| إدارة الفئات | إنشاء وتعديل فئات المساحات |
| إعدادات النظام | تكوين إعدادات المنصة العامة |
| إدارة العمولات | تحديد نسب العمولة وإعدادات الدفع |
| التقارير الشاملة | الوصول لجميع التقارير والتحليلات |
| الدعم الفني | معالجة الشكاوى والمشاكل التقنية |

## 5. وظائف تطبيق الجوال

### 5.1 التسجيل وتسجيل الدخول

#### 5.1.1 إنشاء حساب جديد

**طرق التسجيل**:
- البريد الإلكتروني وكلمة المرور
- رقم الجوال مع رمز التحقق (OTP)
- تسجيل الدخول عبر Google
- تسجيل الدخول عبر Apple ID

**البيانات المطلوبة**:
- الاسم الكامل (إلزامي)
- البريد الإلكتروني (إلزامي)
- رقم الجوال (إلزامي)
- كلمة المرور (8 أحرف كحد أدنى، حرف كبير، رقم، رمز خاص)

**التحقق**:
- التحقق من البريد الإلكتروني عبر رابط
- التحقق من رقم الجوال عبر OTP

#### 5.1.2 تسجيل الدخول

- تسجيل الدخول بالبريد الإلكتروني/كلمة المرور
- تسجيل الدخول برقم الجوال/OTP
- تسجيل الدخول عبر منصات التواصل الاجتماعي
- خيار "تذكرني" للجلسات الطويلة
- تسجيل دخول بالبصمة/Face ID

#### 5.1.3 استعادة كلمة المرور

- إرسال رابط إعادة التعيين للبريد الإلكتروني
- إرسال رمز OTP لرقم الجوال
- أسئلة الأمان (اختياري)

| المعيار | النوع | الوصف |

- السعر لكل ساعة/يوم
- الخدمات المتوفرة (أيقونات)
- حالة التوافر

**عرض الخريطة**:
- دبابيس على الخريطة لكل مساحة
- معلومات مختصرة عند النقر
- تكبير/تصغير وتصفح الخريطة
- تحديد نطاق البحث بالسحب

#### 5.3.3 الفرز والتصفية

**خيارات الفرز**:
- الأقرب إليك
- الأعلى تقييمًا
- الأقل سعرًا

- الأحدث إضافة

### 5.5 عملية الحجز

#### 5.5.1 خطوات الحجز

```
┌─────────────────────────────────────────────────────┐
│                                                     │
│   ①  ──────────  ②  ──────────  ③  ──────────  ④   │
│  اختيار       تفاصيل        الدفع         تأكيد   │
│  الموعد       الحجز                       الحجز    │
│                                                     │
└─────────────────────────────────────────────────────┘
```

**الخطوة 1: اختيار الموعد**
- تحديد التاريخ من التقويم
- اختيار وقت البداية
- اختيار وقت النهاية أو المدة
- عرض السعر التقديري

**الخطوة 2: تفاصيل الحجز**
- عدد الحضور
- الغرض من الحجز (اختياري)
- ملاحظات إضافية
- طلب خدمات إضافية (مشروبات، معدات)

**الخطوة 3: الدفع**
- عرض ملخص الحجز
- اختيار طريقة الدفع
- إدخال بيانات الدفع أو استخدام المحفوظة
- تطبيق كود الخصم (إن وجد)
- تأكيد الدفع

**الخطوة 4: تأكيد الحجز**
- عرض تفاصيل الحجز النهائية
- رقم الحجز المرجعي
- رمز QR للدخول
- خيارات إضافة للتقويم

### 5.6 إدارة الحجوزات

#### 5.6.1 قائمة الحجوزات

**التصنيفات**:
- القادمة: حجوزات مستقبلية
- الجارية: حجوزات حالية
- المكتملة: حجوزات سابقة
- الملغاة: حجوزات تم إلغاؤها

**معلومات كل حجز**:
- اسم المساحة وصورتها
- التاريخ والوقت
- المدة والتكلفة
- الحالة (مؤكد، قيد الانتظار، ملغي)
- رقم الحجز

#### 5.6.2 تفاصيل الحجز

- جميع معلومات الحجز
- رمز QR للدخول
- بيانات التواصل مع المزود
- موقع المساحة على الخريطة
- خيارات: تعديل، إلغاء، إعادة حجز

#### 5.6.3 تعديل الحجز

**القيود**:
- التعديل متاح قبل موعد الحجز بـ 24 ساعة كحد أدنى
- يمكن تعديل التاريخ/الوقت حسب التوافر
- يمكن تعديل عدد الحضور (ضمن سعة المكان)
- فروقات الأسعار تُحسب تلقائيًا

#### 5.6.4 إلغاء الحجز

**سياسة الإلغاء** (قابلة للتخصيص من المزود):
- إلغاء قبل 48 ساعة: استرداد كامل
- إلغاء قبل 24 ساعة: استرداد 50%
- إلغاء قبل أقل من 24 ساعة: بدون استرداد

### 5.7 التقييمات والمراجعات

#### 5.7.1 إضافة تقييم

**الشروط**:
- يجب إتمام الحجز واستخدام المساحة
- التقييم متاح خلال 7 أيام من تاريخ الحجز

**عناصر التقييم**:
- تقييم عام (1-5 نجوم)
- تقييمات فرعية:
  - النظافة
  - الموقع
  - القيمة مقابل السعر
  - الخدمات والمرافق
  - التواصل مع المزود
- نص المراجعة (اختياري)
- صور من الزيارة (اختياري)

### 5.8 الملف الشخصي والإعدادات

#### 5.8.1 إدارة الملف الشخصي

- تحديث الصورة الشخصية
- تعديل الاسم والبيانات

#### 5.8.2 إدارة طرق الدفع

### 7.3 قواعد الحجز

- الحد الأدنى للحجز: ساعة واحدة (قابل للتخصيص)
- الحد الأقصى للحجز: 8 ساعات (قابل للتخصيص)
- أقرب موعد للحجز: بعد ساعتين من الآن
- أبعد موعد للحجز: بعد 90 يومًا
- فترات الحجز: كل 30 دقيقة

#### 7.3.2 قواعد التأكيد

**التأكيد التلقائي**:
- يتم تأكيد الحجز فور الدفع
- يُستخدم للمزودين الذين لا يحتاجون مراجعة يدوية

**التأكيد اليدوي**:
- يظل الحجز "معلق" حتى موافقة المزود
- مهلة الموافقة: 4 ساعات (قابل للتخصيص)
- إلغاء تلقائي عند انتهاء المهلة مع استرداد كامل

4. حق المستخدم في الوصول لبياناته وحذفها
5. الاحتفاظ بالبيانات للمدة اللازمة فقط

### ملحق ج: شروط الاستخدام (ملخص)

1. يجب أن يكون عمر المستخدم 18 عامًا فأكثر
2. المستخدم مسؤول عن دقة معلوماته
3. يحظر استخدام المنصة لأغراض غير قانونية
4. المنصة غير مسؤولة عن نزاعات بين المستخدمين والمزودين
5. يحق للمنصة إيقاف الحسابات المخالفة
